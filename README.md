**Q：搬瓦工 CN2 和 CN2 GIA 有什么区别？**

CN2（即 CN2 GT）是中国电信的二级网络，高峰期有一定拥堵风险；CN2 GIA 是中国电信最高等级的精品网络，全程 QoS 保障，延迟和稳定性都更好，价格也更贵。如果预算允许，直接选 CN2 GIA 或 CN2 GIA-E。

**Q：BandwagonHost 套餐可以更换机房吗？**

可以，但有条件。CN2 GIA-E 套餐支持最多 12–14 个机房之间免费迁移；KVM 套餐支持 8 个机房切换；香港套餐仅限香港本地机房（不可迁出，但可切换到东京/大阪/新加坡）。迁移操作在 KiwiVM 控制面板里完成。

**Q：搬瓦工有限量版套餐是什么意思？**

搬瓦工会不定期推出限量版套餐，配置比同价位常规套餐好很多（通常是常规套餐的配置翻倍或价格减半）。但库存极少，有时几小时就卖完，补货时间不固定，可以订阅补货通知等待。
